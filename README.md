# Week 01 Utils: Mini CRM

Первый учебный проект курса: консольная Mini CRM для работы с заявками клиентов.

Проект помогает:

- собрать бриф клиента;
- посчитать цену услуги;
- сохранить заявку в CSV;
- посмотреть список заявок;
- найти заявку по имени;
- изменить заявку;
- удалить заявку.

## Скрипты

- `hello_client.py` - спрашивает имя клиента и задачу, затем выводит короткое описание заявки.
- `price_calculator.py` - считает цену услуги.
- `brief_generator.py` - создает бриф клиента и сохраняет его в `brief.txt`.
- `leads_saver.py` - сохраняет заявки в `leads.csv`.
- `app.py` - объединяет основные функции в одно меню.

## Как запустить

Если команда `python` уже работает:

```bash
python hello_client.py
```

Если Windows еще не обновил PATH после установки Python:

```bash
C:\Users\stepa\AppData\Local\Programs\Python\Python312\python.exe hello_client.py
```

## Главный файл

Используй `app.py`. Остальные файлы оставлены как учебные шаги.

## Как запустить

```bash
python app.py
```

## Что хранится в файлах

- `leads.csv` - заявки клиентов в формате таблицы.
- `brief.txt` - сохраненные брифы клиентов.

## Где можно применить

Такой проект можно развить в простую CRM для фрилансера, репетитора, салона красоты, мастера или небольшого бизнеса.
