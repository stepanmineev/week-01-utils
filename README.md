# Mini CRM для заявок

Консольная CRM-программа на Python для учета простых клиентских заявок.

Проект сделан как первый практический проект курса "AI-разработчик за 8 недель". Он показывает базовые навыки: ввод данных, проверки, работа с файлами, CSV, функции, меню, Git и простая CRUD-логика.

## Возможности

- собрать бриф клиента;
- посчитать цену услуги со скидкой;
- сохранить заявку в `leads.csv`;
- показать список заявок;
- найти заявку по имени;
- изменить заявку;
- удалить заявку;
- сохранить бриф в `brief.txt`;
- проверить GitHub-профиль через API;
- безопасно спрашивать числа в калькуляторе цены.

## Главный файл

Запускай:

```bash
python app.py
```

Остальные `.py` файлы оставлены как учебные шаги, из которых постепенно собирался `app.py`.

## Структура

- `app.py` - основная программа с меню.
- `leads.csv` - таблица заявок.
- `brief.txt` - сохраненные брифы.
- `hello_client.py` - первый учебный скрипт.
- `price_calculator.py` - расчет цены.
- `brief_generator.py` - генератор брифа.
- `leads_saver.py` - сохранение заявки в CSV.
- `leads_reader.py` - чтение заявок из CSV.
- `api_client.py` - первый запрос к внешнему API через `requests`.
